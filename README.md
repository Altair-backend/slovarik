# Словарик

Офлайн-приложение для заучивания слов в духе Quizlet: папки, наборы, карточки,
четыре режима обучения, интервальное повторение, статистика, напоминания и виджеты.

Kotlin · Jetpack Compose (Material 3) · Room · Hilt · WorkManager · Glance · Android 8.0+ (API 26)

## Архитектура

MVVM в одном модуле `app`:

- **data** — Room (таблицы `folders`, `sets`, `cards`, `study_log`), `Repository` как единая точка
  доступа к данным, `SettingsStore` (DataStore) для настроек, `BackupManager` для экспорта и копий.
- **domain** — чистая логика без Android: SM-2, проверка ответа, разбор импорта, серия дней.
- **ui** — экраны на Compose. У каждого экрана свой `ViewModel` (Hilt), состояние отдаётся
  через `StateFlow`. Экран и его ViewModel лежат в одном файле.
- **widget** — два виджета Glance и воркер обновления.
- **notifications** — воркер ежедневного напоминания.

Виджеты и воркеры создаёт система, поэтому зависимости они получают через Hilt `EntryPoint`
(`di/AppModule.kt`), а не через конструктор.

## Принятые решения

- **Папки плоские**, набор лежит в одной папке или без папки. «Перемещение» — это перенос набора
  между папками (меню набора → «Переместить в папку»). Удаление папки наборы не удаляет.
- **Заучивание**: каждое слово проходит два шага — выбор из 4 вариантов (термин → перевод), затем
  ввод термина с клавиатуры. Раунды по 7 слов; ошибочное слово возвращается в том же раунде.
- **SM-2** записывается один раз, когда слово пройдено (и один раз при первой ошибке), чтобы два
  верных ответа подряд в одной сессии не сдвигали повторение сразу на 6 дней.
- **«Выучено»** — уровень знания 3 из 5 и выше. Уровень растёт за верные ответы и падает за ошибки.
- **Резервная копия** — zip-архив: `data.json` и картинки. Восстановление заменяет все данные.
- **Виджет «Слово дня»** один, но с двумя раскладками: 2×2 (маленький) и от 4×2 (средний) —
  размер меняется растягиванием. Слово меняется каждые 6 часов и по кнопке.
- **Напоминание** идёт через WorkManager, поэтому может прийти на несколько минут позже заданного
  времени — точные будильники потребовали бы отдельного разрешения.
- **Целевая версия** — API 36 (Android 16). Чтобы перейти на более новую, поменяйте `compileSdk`
  и `targetSdk` в `app/build.gradle.kts` и согласитесь на обновление плагина, если Studio предложит.
- Тексты интерфейса написаны прямо в коде на русском: язык у приложения один.

## Как запустить (для новичка)

### 1. Установить Android Studio
1. Скачайте Android Studio с официального сайта developer.android.com/studio и установите,
   оставляя настройки по умолчанию.
2. При первом запуске мастер сам скачает Android SDK — дождитесь окончания.

### 2. Открыть проект
1. Распакуйте архив в папку с простым путём без кириллицы, например `C:\Projects\Slovarik`.
2. В Android Studio: **File → Open** → выберите папку `Slovarik` (ту, где лежит `settings.gradle.kts`).
3. Внизу появится «Gradle sync». Первый раз он идёт 5–15 минут и требует интернет: скачиваются
   библиотеки. Дождитесь надписи «Sync finished».
4. Если Studio предложит обновить Gradle Plugin — можно отказаться («Don't remind me again»).

### 3. Запустить на телефоне по USB
1. На телефоне: **Настройки → О телефоне** → семь раз нажмите на «Номер сборки» — включится
   режим разработчика.
2. **Настройки → Система → Для разработчиков** → включите «Отладка по USB».
   На Xiaomi дополнительно включите «Установка через USB».
3. Подключите телефон кабелем, на телефоне подтвердите «Разрешить отладку».
4. В Android Studio вверху выберите свой телефон в списке устройств и нажмите зелёный
   треугольник **Run** (Shift+F10). Приложение установится и откроется.

### 4. Или собрать APK
1. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
2. Когда появится уведомление, нажмите **locate**. Файл лежит в
   `app/build/outputs/apk/debug/app-debug.apk`.
3. Перенесите его на телефон и откройте. Телефон попросит разрешить установку из этого
   источника — разрешите.

### 5. Добавить виджет
1. Сначала один раз откройте приложение.
2. Нажмите и удерживайте пустое место на рабочем столе → **Виджеты**.
3. Найдите «Словарик», перетащите «Слово дня» или «Прогресс» на экран.
4. Для «Слова дня» откроется выбор набора или папки. Чтобы получить средний размер,
   удерживайте виджет и растяните его по ширине.

## Если сборка не прошла

Скопируйте текст ошибки из вкладки **Build** целиком. Чаще всего это одна строка в одном файле,
её быстро поправить.
